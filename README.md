# Praveen Sasikumar · Personal Website

A one-page portfolio for Praveen Sasikumar, PhD student at the National University of Singapore. The site presents his experience, selected projects, research and contact links.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Content and assets

- `index.html` contains the site content, publication links and animated project diagrams.
- `assets/config.js` contains the profile map locations and years.
- `assets/style.css` contains the visual styles and figure animations.
- `assets/site.js` provides the map, motion controls and responsive navigation.
- `assets/praveen-sasikumar-cv-2026.pdf` is the downloadable CV.

The site uses plain HTML, CSS and JavaScript and has no build step.
